The Agentic AI Layer is a multi-channel agent platform architected at Daxonet AI. Agents connect accounting and business systems through APIs and role-restricted MCP tools.

It uses Claude Agent SDK workflows, Gemini-backed memory and Pipecat voice, and is reachable over Telegram and WhatsApp. Google Workspace and Microsoft Graph are integrated using OAuth with PKCE and encrypted token storage.

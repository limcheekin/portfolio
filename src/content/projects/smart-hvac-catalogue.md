The Smart HVAC Catalogue System is a RAG backend built at Daxonet AI that matches air-conditioners to room type, size and usage.

It combines PDF ingestion, dense and sparse retrieval, and product filters. Ingestion is asynchronous, and the system includes LLM evaluation and observability, with tests and evaluations running in GitHub Actions.

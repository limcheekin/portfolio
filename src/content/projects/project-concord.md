Project Concord is a Model Context Protocol (MCP) server that connects modern AI agents with legacy database schemas. It gives agents access to enterprise databases, with permission controls governing which tools they can use.

It is written in TypeScript and packaged with Docker. For the background, see the article [AI is Ready. Your Legacy Database Isn't. Let's Fix That.](/insights/legacy-database-ai/).
